### Work Instruction
1. Input the serial number.
2. Connect the LED Board to the Control Board.
3. Press the right button (labeled LED) on the Control Board once to enable Mode 1.
4. Start the test.
5. Press the button again when prompted to enable Mode 2. Repeat for Mode 3.
